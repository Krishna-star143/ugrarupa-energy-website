UGRARUPA ENERGY - STATIC WEBSITE PACKAGE

Included:
- index.html: complete one-page corporate website
- styles.css: responsive layout and styling
- script.js: mobile navigation, year and enquiry email action
- assets/ugrarupa-energy-logo.webp: company logo supplied by the user

HOW TO PREVIEW:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. An internet connection is needed for Google Fonts and remote photography.

HOW TO PUBLISH FREE:
Option A - Netlify:
1. Create/sign in to a Netlify account.
2. Choose Add new site > Deploy manually.
3. Drag the extracted website folder (the folder containing index.html) into the upload area.
4. Netlify will provide a free public URL ending in netlify.app.

Option B - GitHub Pages:
1. Create a GitHub repository and upload index.html, styles.css and script.js.
2. Open repository Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
